# Portal Overview

- Plant, Project, and District choices show all values available to the signed-in user and do not narrow one another. Dashboard access is portfolio-wide for O&M Head, Assignee, and Administration; Site Engineers remain restricted to assigned plants.
- The default Dashboard range is This month. Summary tiles and trends use the selected date range.
- Browser Back and Forward restore visited portal views without reloading the page. Private O&M data is not cached for offline use.
- Clicking PM Compliance, Washing Compliance, or Open Site Issues opens the matching page in Overview when All plants is selected. When one plant is selected, it opens that plant's matching page. The selected date range is carried to the destination.
- The operational trend is a grouped bar chart for the selected plant or plants. Plant, Project, and District filters narrow the trend.
- Washing compliance is the percentage of configured cycles due in each bucket that were confirmed complete on or before their configured due date. Plants without a washing setup are omitted from its denominator.
- PM compliance is the percentage of non-cancelled tasks due in each bucket that were completed on or before their effective planned due date.
- Active site issues are the currently open issue records grouped by their `occurred_at` date; this series is not a historical snapshot of issue status.
- The Module Cleaning portfolio board in Overview defaults to the current month and has a month picker for any past month. Plant, cycle, cleaning-date, and date-specific Entry status filters use that month's plants and dates. Selecting a date shows all visible plants; Entry status can narrow the list to submitted reports or plants with no report. The status filter uses the role-scoped daily washing endpoint and excludes inactive plants from the missing-entry results. A plant's Module Cleaning calendar has previous/next navigation and Week/Month views; washing day cells show the saved cleaned-table count and recorded table numbers, or say when legacy records have no numbers.
- Health pages in both Plants and Overview provide an occurrence-date filter styled like Dashboard: it defaults to the current month, offers quick periods, a month picker for past months, and a toggle for a custom From–To range. Date bounds are sent to the role-scoped issue API, so paging and older months use matching records rather than only filtering the newest page. Clear filters removes the date filter.
- Clicking an issue row opens that plant's Health page; Module Cleaning cards open that plant's cleaning calendar. A saved PM or cleaning record links from its detail dialog to the plant's matching module page.
- In the portfolio Health register, O&M Head and Assignee open supported column filters from compact header arrows, then search or select a loaded value. The desktop table fits all columns without a horizontal scrollbar. Occurrence dates show the elapsed day count; other roles do not see these controls.
- In Overview → Details, O&M Head and Assignee open searchable value lists from compact column-header arrows; the full filter controls stay hidden until opened.
- The Security register lists multiple site engineers and guards per visible plant, with separate 10-digit mobile number fields and a Day/Night duty shift for each person. O&M Head edits contacts in the searchable, site-filtered overlay; Administration can view them. Contacts are stored with the plant record, and other roles do not receive the contact fields.
- Compliance percentages use the left axis (0–100%); issue counts use the right axis. Buckets are daily through 31 days, weekly through 366 days, then monthly. Requests are bounded to 10 years.
