Install Solar91 O&M

If the install prompt is unavailable, open this portal in your browser and use its install option:

  • Android: browser menu ⋮, then Install app or Add to Home screen.
  • iPhone or iPad: in Safari, tap Share, then Add to Home Screen.
  • Windows: in Edge or Chrome, use the install icon in the address bar or the browser menu.

If you removed the installed app, open the portal in a regular browser tab to add it again.
